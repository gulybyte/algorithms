# Basic Shift Cipher Algorithm

Um algoritmo simples de cifra de substituição é onde cada caractere de uma palavra é substituído por um número fixo de posições.

Por exemplo, no algoritmo de ceaser, ao shift é 3

![](https://media.geeksforgeeks.org/wp-content/uploads/ceaserCipher-1.png)

No ROT13 o shift é 13

![](https://cscx.org/rot13.svg)

No [script lua nesse diretorio](main.lua), há um exemplo Basic Shift Cipher Algorithm, que serve para o Ceaser e o ROT13, apenas necessitando alterar o valor de shift.
