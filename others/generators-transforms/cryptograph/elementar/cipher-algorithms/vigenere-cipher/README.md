# Vigenere Cipher

É algoritmo de cifra in which the encryption key is repeated multiple times spanning the entire message, and then the cipher text is generated by adding the message character with key character modulo 26.

Na prática, vamos definir `plainText = 'attack'` e `key = 'KEY'`, então extendemos `key` de forma que tenha o mesmo tamanho que `plainText`, no caso teremos `extendedKey = 'KEYKEY'`. Então podemos usar essa uma matriz $M_{m\times n}$ que repete o alfabeto, sendo $n$ e $m$ iguais a $26$:
![](https://www.researchgate.net/publication/318260132/figure/fig3/AS:513402955104258@1499416211147/Vigenere-Cipher-table.png)

e relacionar a coluna da primeira letra do plainText com a linha da primeira letra da extendedKey. Assim então, termos `cipherText = kxrkgi`

[Para entender melhor, veja esse video](https://youtu.be/SkJcmCaHqS0)

Para implementar o algoritmo em linguagem de programação (no caso, usaremos Lua), tereos que implementar essa equação simples:

### $$C = (P+K)(\text{mod } m)$$

onde $C$ é o `cipherText`, $P$ é o `plainText`, $K$ é a `extendedKey` e $m$ é o tamanho do alfabeto, no caso $26$. Essa equação no caso serve para encriptar o `plainText`, caso queiramos decriptar o `cipherText` teremos a outra seguinte equação:

### $$P = (C-K)(\text{mod } m)$$
